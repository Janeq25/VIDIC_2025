
Requirements:

1. Module shall deassert all output signal when reset signal is active.

2. Module shall ignore two uart frames when either one of frames start_bits is incorrect.

3. Module shall ignore two uart frames when either one of frames parity_bits is incorrect.

4. Module shall ignore two uart frames when either one of frames stop_bits is incorrect.

5. Module shall hold all outputs high when programming mode is selected.

6. Module shall store address and port combination sent as two frames to serial input when programming mode is selected.

7. Module shall direct both address and data sent as two frames to serial input with accordance to stored address port combination when functional mode is selected.


Test plan:

0.  Reset module

1. Send Correct packet and check if it is present on sout0

2. Send packet with incorrect start bit in address frame and check if it was ignored

3. Send packet with incorrect parity bit in address frame and check if it was ignored

4. Send packet with incorrect stop bit in address frame and check if it was ignored

5. Send packet with incorrect start bit in data frame and check if it was ignored

6. Send packet with incorrect parity bit in data frame and check if it was ignored

7. Send packet with incorrect stop bit in data frame and check if it was ignored

8. Set rst_n active and check state of outputs

9. Set prog active and check state of outputs
